How to use
  1. Close any IDE that is connected to the robot over Bluetooth (USB is fine).
  2. Start a program that uses phone control over Bluetooth: start: switch the robot on with it saved as main.py, or click Run over USB.
  3. Tap Connect and choose the robot (its name starts with XRP-).

Joystick: up is forward (+), right is right (+), both -100 to 100. D-pad: Up = 1, Left = 2, Right = 3, Down = 4, A = 5, B = 6. Your program decides what each input does.

If you switch apps, lock the phone or lose the link, every input is released and the robot sees "not connected" within a second. The program must stop the motors itself.
